# key-reader
Печатный трекер, который считывает клавиши клавиатуры, которые затем использует полученные данные, чтобы узнать на какой клавиатурной раскладке пишет пользователь.

## Печатный трекер
  https://github.com/boppreh/keyboard
Цель - взять данные нажатия клавиш
Их хранение
## Анализ данных
https://www.researchgate.net/publication/324659119_Observations_on_Typing_from_136_Million_Keystrokes
Определение важных характеристик из данных, чтобы с ними можно как-то взаимодействовать
Правильность написания слов
Специальные символы

## Раскладки клавиатур
https://kbdlayout.info/
Есть раскладки клавиатур, есть язык на котором он печатается. Keyboard библиотека распознает раскладку, но отображает на английском языке (из тестирования, но не 100% знаю)

## Приложение для взаимодействия (идеи)
### Тренировка печтания
Берет данные из обычной компьютерной деятельности
смотрит какие буквы и символы имели больше всего ошибок 
Готовит тренировочный материал
### Система комбо
Гемификация печатания на компьютере
Комбо следит за скоростью и уверенностью печати (без backspace например) в реальном времени
### Идея игры
https://github.com/boppreh/keyboard позволяет не только считывать данные клавиатуры, но и вставлять свой текст
Можно создать некую игру, где иногда игра запрашивает, чтобы пользователь писал странным способом (например сещением на один влево, или с перевернутым регистром), но при этом исправлять этот текст на лету
### Формулятор идей
Визуализация написанного текста с возможностью контролировать его структуру на лету (возможно можно также как-то отделять части и их менять местами, и чтобы текст в текстовом документе менялся в реальном времени)
